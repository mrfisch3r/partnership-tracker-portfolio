# Partnership / Resource Tracker (UK HealthCare Capstone)

A full-stack web application prototype sponsored by **The Health Education Manager at UK HealthCare** to address a core problem: there was **no centralized database for community resource details**, which created accuracy issues, mishandling, and confusion.

This project centralizes partnership/resource data and provides role-aware workflows for staff and supervisors.

## Problem
- No centralized database for community resource details
- Resulted in data accuracy issues, mishandling issues, and general confusion

## Solution
A web application to centralize the data and make it easier for UK HealthCare staff to maintain and trust resource/partnership information.

## Key features (implemented)
- Upload prior spreadsheet data to avoid re-entry and reduce errors
- Staff can enter and manage community partner/resource data
- Staff can view and delete their own entries
- Supervisors can see who added which entries (accountability / audit trail)
- Supervisors can edit team member entries as needed

## Architecture / Tech stack
- **Frontend:** React (web UI)
- **Backend:** Flask + Flask-CORS + Flask-SQLAlchemy (REST API / JSON)
- **Data:** SQLAlchemy ORM + SQLite
