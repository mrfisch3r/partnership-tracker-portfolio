# How to run this prototype

## 1. Start the backend Flask
a. In the VS Code Terminal, make sure you are in the project root directory: PARTNERSHIP-TRACKER-PROTOTYPE/

b. Run python app.py

c. You'll see: Running on http://127.0.0.1:5000

## 2. Start the frontend
a. Open a new terminal, Enter the front-end project directory: cd client/partnership-tracker

b. Run npm install

c. Run npm run dev

d. You'll see:

VITE v4.x running at:
Local: http://localhost:5173/

## 3. Access to the website
a. Now open http://localhost:5173/

b. If there is data in the database, it will be displayed in the table: http://localhost:5000/api/partners
