# How to run this prototype

## 1. Start the backend Flask
- In the VS Code Terminal, make sure you are in the project root directory: PARTNERSHIP-TRACKER-PROTOTYPE/

- Run python app.py

- You'll see: Running on http://127.0.0.1:5000

## 2. Start the frontend
- Open a new terminal, Enter the front-end project directory: cd client/partnership-tracker

- Run npm install

- Run npm run dev

- You'll see:

VITE v4.x running at:
Local: http://localhost:5173/

## 3. Access to the website
- Now open http://localhost:5173/

- If there is data in the database, it will be displayed in the table: http://localhost:5000/api/partners
